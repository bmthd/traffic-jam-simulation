「追いつかれた車両の義務」で渋滞は本当に減るのか？

同じ条件の高速道路を2本並べて走らせ、「追いつかれた車両の義務」というルール1つの有無だけで渋滞のできかたがどう変わるかを観察する、ブラウザで動く3D交通シミュレーションです。インストール不要で、無料で自由に触れます。

何と何を比べているのか

画面には2本の道路が並んでいます。緑の標識の区間（義務あり）では、後ろから速い車に追いつかれたドライバーが追い越し車線を空けて走行車線へ戻ります。オレンジの標識の区間（義務なし）では、譲らないドライバーが混ざり、追い越し車線に留まり続ける車も現れます。

車の性能、車間の取り方、加速・減速のくせ、合流のしかた、交通量といった条件は両区間で共通です。違いはこのルール1つだけなので、生まれた差はそのルールに由来すると考えられます。「パラメータ調整室」で値を変えても、変更は必ず両区間へ同じように適用されます。

どちらの走り方が正しいかを示すためのものではありません。ルールの有無で結果が変わるのか、変わるとしたらどのくらいなのかを、自分の目で確かめるための対照実験です。

「追いつかれた車両の義務」とは

「追いつかれた車両の義務」は、日本の道路交通法第27条が定めるルールの通称です。後ろから来た車に追いつかれ、その車より速く走ることができないときに、速度を上げないことと、進路を譲ることを求めるものです。

このシミュレーションは条文を厳密に再現したものではなく、「速い車に追いつかれたら追い越し車線を空ける」という運転行動としてモデル化したものです。実際の交通ルールの解説や法的な助言を目的とするものではありません。

渋滞スコアの見かた

画面下の「渋滞スコア比較」には、区間ごとの車両数・平均速度と、0〜100の渋滞スコアが並びます。スコアは平均速度の落ち込みと区間内の混み具合（台数）から計算し、値が大きいほど詰まっている状態を表します。「優勢だった時間」は、開始からどちらの区間がスムーズだった時間が長いかの累計です。

操作方法

  • ドラッグ（スマートフォンではスワイプ）で視点を回し、ホイール（ピンチ）で拡大・縮小します。
  • 右上のボタンで昼夜の切り替えと、カメラ視点の切り替えができます。
  • 「パラメータ調整室」で交通量やドライバーのくせを変えられます。値は両区間へ共通に適用されます。
  • 「リセット」で最初からやり直せます。

制作について

Three.js と TypeScript で作った個人制作の実験です。ソースコードは GitHub で MIT ライセンスのもとに公開しています。

調パラメータ調整室
公平性について: ここにある値はすべて両区間のドライバーに共通です。 左右の違いは「速い車に追いつかれたら譲るか」というルールだけ。 値を自由に動かして、それでも差が出るか確かめてください。
※ 交通量はすぐに反映されます。ドライバーの性格に関わる値は「リセットして適用」で全車両を作り直すと完全に反映されます。
