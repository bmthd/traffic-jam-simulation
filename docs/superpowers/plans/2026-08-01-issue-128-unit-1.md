# Issue #128 ユニット1（基盤）実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 周回路を3264mへ延長し、現行と等価な入口ランプをL/R共通条件で4施設へ配置する。

**Architecture:** 周長と施設メタデータは `constants.ts` を単一の情報源にし、全ランプ判定は `toFacilityLocalZ(z)` で施設0の座標へ正規化してから行う。需要台数は旧周長816mに対する現周長比で算出し、ランプ流入の施設番号はL/Rペアごとに一度だけ抽選する。

**Tech Stack:** TypeScript、Vitest、Vite+

## Global Constraints

- L/R の新しい挙動差を作らず、施設種別をコア分岐に使わない。
- `vehicle.ts` の終端流出処理と `src/render/` は変更しない。
- 新規テストは `traffic-simulation.test.ts` 末尾の独立 `describe` に置く。
- 各実装段階で `pnpm check` と `pnpm test` を実行する。
